# 🏋️ FitHeaven

## 📌 Overview

FitHeaven is an interactive fitness tracking web application designed to help users maintain a healthy lifestyle by tracking workouts, calories, and daily activities.

The system enhances user engagement through dynamic motivational quotes, reward-based features, and interactive UI elements.

---

## ✨ Features

* 🏋️ Workout tracking system
* 🔥 Calorie monitoring
* 🎯 Reward-based motivation system
* 📅 Schedule management
* 💬 Dynamic motivational quotes
* 🎨 Interactive UI with hover effects
* 📊 User-friendly dashboard

---

## 🛠 Tech Stack

* HTML
* CSS
* JavaScript

---

## ▶️ How to Run

2. Open index.html in browser
